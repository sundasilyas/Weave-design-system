How to use

Every page loads Inter from Google Fonts in weights 400, 500, 600 and 700. Add this to the <head> of a page:

HTML 
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap">

Then set the font in CSS. The other fonts are fallbacks while Inter loads:

CSS 
font-family: "Inter", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;

Responsive type scale

Larger styles grow on bigger screens. Resize the window to see the sizes change. Letter spacing is -0.02em for Display and H1, -0.01em for H2, and 0 for everything else.

Accessibility

Type choices decide whether people can read our products at all. These rules come from the Web Content Accessibility Guidelines (WCAG). Each one has a live example: try the controls.

Resizable text WCAG 1.4.4

Many people make text bigger to read it. Text must still work at 200%: nothing cut off and nothing overlapping. So containers grow with their text instead of having a fixed height.

100%

Text spacing WCAG 1.4.12

Some people use tools that add space between lines, paragraphs, letters and words. Text must stay readable when they do. Try the toggle: it applies line height 1.5×, paragraph spacing 2×, letter spacing 0.12em and word spacing 0.16em.

Readable text blocks WCAG 1.4.8

Long lines, justified or centred paragraphs and long runs of italics are all harder to read, especially for people with dyslexia or low vision.

Contrast WCAG 1.4.3

Text needs enough contrast with its background: at least 4.5:1 for body text and 3:1 for large text. The ratios below are worked out from tokens.css.

See every colour pairing in the contrast matrix on the Colours page.

Structure WCAG 1.3.1 and 1.4.1

Screen reader users jump from heading to heading to find their way, so heading levels must go in order without skipping. And links need more than colour to stand out, so people who can't tell colours apart can still find them.
